# Site automachine.net

Site vitrine d'Automachine, généré avec Astro. Lire `CLAUDE.md` pour les décisions du projet
et le dossier `docs/` pour les procédures (édition, déploiement, 3D, bascule, reprise).

## Commandes

| Commande          | Action                                        |
| ----------------- | --------------------------------------------- |
| `npm install`     | Installe les dépendances                      |
| `npm run dev`     | Serveur de développement sur `localhost:4321` |
| `npm run build`   | Construit le site dans `dist/`                |
| `npm run preview` | Prévisualise le site construit                |
